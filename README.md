# IRANBOT --- Telegram Config Shop

**نسخه: v1.0.3**

این نسخه ادامه‌ی نسخه‌های قبلی IRANBOT است و قابلیت‌های فروش کانفیگ، کیف
پول، پرداخت، تست رایگان، پنل‌های Marzban / Pasarguard / 3x-ui و مدیریت
کامل از طریق Web Panel را یکجا دارد.

## 🆕 تغییرات نسخه 1.0.3

### 👥 مدیریت کاربران فقط از Web Panel

مدیریت کاربران به‌صورت کامل به **Web Panel** منتقل شده و بخش مدیریت
کاربران از منوی مدیریت داخل ربات حذف شده است.

در Web Panel می‌توان: - کاربران را مشاهده و جستجو کرد. - کاربر را با ID،
Username یا نام پیدا کرد. - موجودی را افزایش یا کاهش داد. - کاربر را
Block / Unblock کرد. - سفارش‌ها و سرویس‌های تأییدشده را دید. -
Subscription سرویس‌های کاربر را مشاهده کرد.

### 🔔 اطلاع‌رسانی تغییر موجودی

وقتی موجودی کاربر از طریق Web Panel تغییر کند، ربات به همان کاربر پیام
اطلاع‌رسانی ارسال می‌کند.

### 💳 اصلاح نمایش کارت

در صفحه **کیف پول** دیگر شماره کارت و نام صاحب کارت نمایش داده نمی‌شود.

**شماره کارت و نام صاحب کارت فقط هنگام ورود کاربر به مرحله پرداخت یا
شارژ کیف پول نمایش داده می‌شود.**

### 🧪 تست اتصال پنل از Web Panel

برای پنل‌های ثبت‌شده امکان تست اتصال مستقیم از Web Panel اضافه شده است: -
Marzban - Pasarguard - 3x-ui

نتیجه تست به‌صورت وضعیت موفق یا خطا نمایش داده می‌شود.

### 🔗 مدیریت Groupهای Pasarguard از Web Panel

ادمین می‌تواند از Web Panel: - Groupها را از پنل دریافت کند. - Groupها را
مشاهده کند. - چند Group را انتخاب کند. - Groupهای مورد استفاده برای ساخت
سرویس را ذخیره و مدیریت کند.

### 🎁 تنظیم کامل تست رایگان از Web Panel

ادمین می‌تواند تنظیمات Free Test را از Web Panel کنترل کند: - تعداد تست
مجاز هر کاربر - حجم تست بر حسب MB - مدت تست بر حسب ساعت - فعال/غیرفعال
بودن تست - پنل مورد استفاده برای تست

کاربر حجم و مدت تست را انتخاب نمی‌کند و دقیقاً تنظیمات تعیین‌شده توسط ادمین
را دریافت می‌کند.

### 🎨 بازطراحی گرافیکی Web Panel

Web Panel از حالت ساده و خشک خارج شده و ظاهر جدید و گرافیکی دارد: -
داشبورد آماری - کارت‌های اطلاعاتی - وضعیت‌های رنگی - دکمه‌های مرتب - طراحی
ریسپانسیو برای موبایل و دسکتاپ - نمایش بهتر کاربران، سفارش‌ها، پنل‌ها و
تنظیمات

### 👤 ثبت کاربر از `/start`

کاربر از همان زمانی که `/start` را می‌زند در دیتابیس ثبت یا به‌روزرسانی
می‌شود؛ حتی اگر هنوز عضویت اجباری را کامل نکرده باشد.

### 🛠 رفع خطای بخش Users

Migration جدول کاربران مقاوم‌تر شده تا کمبود ستون‌های جدید در دیتابیس
نسخه‌های قبلی باعث خطای 500 در صفحه Users نشود.

1.  کاربر محصول را انتخاب می‌کند.
2.  مبلغ دقیق نمایش داده می‌شود.
3.  شماره کارت و نام صاحب کارت نمایش داده می‌شود.
4.  کاربر رسید را ارسال می‌کند.
5.  رسید برای ادمین ارسال می‌شود.
6.  ادمین تأیید یا رد می‌کند.
7.  در صورت تأیید، سرویس ساخته می‌شود.
8.  لینک Subscription برای کاربر ارسال می‌شود.

دسترس است.

# 🚀 نصب روی Railway

Repository پروژه را به Railway متصل کنید.

متغیرهای محیطی:

``` text
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
ADMIN_IDS=123456789
DB_PATH=/app/data/shop.db
```

در صورت نیاز می‌توان `WEB_SECRET` را نیز تنظیم کرد.

## SQLite و Volume

برای حفظ اطلاعات بعد از Redeploy، Railway Volume را روی مسیر زیر قرار
دهید:

``` text
/app/data
```

**دیتابیس و Volume قبلی را حذف نکنید.**
