## 📂 سیستم دسته‌بندی محصولات

سیستم دسته‌بندی محصولات به **Telegram Bot** و **Web Panel** اضافه شده است.

### 🤖 مدیریت دسته‌بندی در Telegram Bot

ادمین از بخش مدیریت می‌تواند:

```text
📂 دسته‌بندی محصولات
```

را باز کند.

سپس:

```text
➕ ساخت دسته‌بندی
        ↓
وارد کردن نام دسته‌بندی
        ↓
ساخت و ذخیره
```

امکانات:

- ساخت دسته‌بندی
- نمایش دسته‌بندی‌ها
- مدیریت دسته‌بندی‌ها
- امکان حذف دسته‌بندی
- اتصال محصول به دسته‌بندی
- امکان ساخت محصول بدون دسته‌بندی

### 🌐 مدیریت دسته‌بندی در Web Panel

در بخش محصولات Web Panel می‌توان:

- دسته‌بندی ایجاد کرد
- محصول را ویرایش کرد
- محصول را به یک دسته‌بندی اضافه کرد
- محصول را بدون دسته‌بندی نگه داشت

هنگام ساخت محصول نیز می‌توان انتخاب کرد:

```text
📂 انتخاب دسته‌بندی
یا
بدون دسته‌بندی
```

### 🛒 نمایش دسته‌بندی‌ها هنگام خرید

در بخش محصولات کاربر:

```text
🛒 محصولات
        ↓
محصولات بدون دسته‌بندی
        ↓
📂 دسته‌بندی‌ها
```

محصولات بدون دسته‌بندی از ابتدا نمایش داده می‌شوند.

سپس دسته‌بندی‌ها با نام خودشان نمایش داده می‌شوند.

با انتخاب یک دسته‌بندی:

```text
📂 دسته‌بندی
        ↓
نمایش محصولات همان دسته
```

اگر دسته‌بندی خالی باشد:

```text
این دسته‌بندی فعلاً خالی است.
```

محصولاتی که در هیچ دسته‌بندی قرار نگرفته‌اند نیز همچنان در همان ابتدای بخش محصولات نمایش داده می‌شوند.

## 🔑 Password Generator

در:

```text
🌐 Web Panel
   ↓
⚙️ تنظیمات
   ↓
🔑 Password Generator
```

بخش تولید رمز عبور اضافه شده است.

ادمین می‌تواند تعداد کاراکترها را وارد کند، مثلاً:

```text
12
```

و سپس روی:

```text
Generate
```

بزند.

رمز تولیدشده شامل ترکیبی از:

```text
حروف کوچک
حروف بزرگ
اعداد
کاراکترهای Special
```

است.

طول رمز دقیقاً مطابق عدد واردشده خواهد بود.

مثال:

```text
Length: 12
        ↓
Generate
        ↓
aB7@kP2#xQ9m
```

امکان:

```text
📋 Copy
```

برای کپی کردن رمز تولیدشده نیز وجود دارد.

طول قابل انتخاب:

```text
4 تا 128 کاراکتر
```

تخفیف قبل از پرداخت روی مبلغ نهایی اعمال می‌شود و در پرداخت مستقیم و پرداخت از کیف پول لحاظ می‌شود.

## 💾 سیستم Backup و Restore

### 🤖 داخل Telegram Bot

در منوی مدیریت بخش جدید:


امکانات:

```text

```

### 📥 گرفتن Backup

ادمین می‌تواند در هر زمان یک Backup کامل از دیتابیس SQLite دریافت کند.

Backup به‌صورت یک کپی سازگار از دیتابیس ساخته می‌شود و فایل `.db` در اختیار ادمین قرار می‌گیرد.

### 📤 Restore

ادمین می‌تواند فایل Backup را وارد Bot کند.

فرمت‌های قابل قبول:

```text
.db
.sqlite
.sqlite3
```

قبل از Restore فایل بررسی می‌شود:

```text
✓ SQLite integrity check
✓ بررسی جدول‌های اصلی
✓ بررسی معتبر بودن دیتابیس
```

بعد از تأیید، دیتابیس جدید جایگزین دیتابیس فعال می‌شود.

### ⏰ Backup خودکار هر 7 روز

ادمین می‌تواند Backup هفتگی را فعال کند.

روند کار:

```text
فعال‌سازی
   ↓
بررسی زمان آخرین Backup
   ↓
هر 7 روز
   ↓
ساخت Backup
   ↓
ارسال Backup برای ADMIN_IDS
```

تنظیم فعال/غیرفعال بودن Backup و زمان آخرین ارسال در دیتابیس ذخیره می‌شود.

### 🌐 Backup در Web Admin Panel

در Web Panel نیز بخش:

```text
💾 پشتیبان‌گیری
```

اضافه شده است.

امکانات:

```text
📥 دانلود Backup
📤 Restore Backup
1️⃣ فعال کردن Backup هفتگی
2️⃣ غیرفعال‌سازی Backup هفتگی
```

تنظیم Backup هفتگی در Bot و Web Panel مشترک است.

⚠️ توکن واقعی خودتان را داخل GitHub یا README قرار ندهید.



# ☁️ نصب روی Railway

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/xX2gKW?referralCode=RL7ALm&utm_medium=integration&utm_source=template&utm_campaign=generic)

> 🚀 **نصب سریع با دکمه بالا:** با زدن دکمه **Deploy on Railway** مستقیماً وارد صفحه Deploy پروژه در Railway می‌شوید و می‌توانید مراحل نصب را سریع‌تر انجام دهید.
>
> 🛠️ **نصب دستی:** اگر نخواستید از دکمه بالا استفاده کنید، مراحل پایین را به‌صورت دستی انجام دهید؛ یعنی Repository را Fork کنید، در Railway پروژه بسازید، Volume و Environment Variables را تنظیم کنید و سپس Deploy بگیرید.

## مرحله 1 — Fork کردن پروژه

اگر پروژه روی GitHub قرار دارد:

1. وارد Repository شوید.
2. بالای صفحه روی **Fork** کلیک کنید.
3. حساب GitHub خودتان را انتخاب کنید.
4. یک Repository جدید برای پروژه ساخته می‌شود.

ساختار ساده:

```text
Original Repository
       │
       └── Fork
             ↓
       Your GitHub Repository
```

### چرا Fork؟

با Fork یک کپی از پروژه داخل حساب GitHub خودتان دارید و می‌توانید آن را مستقل تغییر دهید و به Railway متصل کنید.

---

# 🚂 مرحله 2 — اتصال Fork به Railway

در Railway:

```text
New Project
   ↓
Deploy from GitHub Repo
   ↓
انتخاب Repository خودتان
   ↓
Deploy
```

Railway پروژه را از GitHub دریافت و Build می‌کند.

بعد از هر Push جدید به Repository، در صورت فعال بودن اتصال GitHub، می‌توانید پروژه را دوباره Deploy کنید.

# ⚙️ تنظیمات اولیه

بعد از اولین اجرای موفق:

### 1. پنل VPN را اضافه کنید

مثلاً:

```text
Name: PG-01
Type: Pasarguard
Address: https://panel.example.com
Username: admin
Password: ********
```

### 2. تست اتصال

اتصال پنل را تست کنید.

### 3. Group ها

برای Pasarguard:

```text
Panels
→ Groups
→ دریافت Group ها
→ انتخاب Group
→ ذخیره
```

### 4. کارت بانکی

در Finance شماره کارت و نام صاحب کارت را تنظیم کنید.

### 5. محصول

محصول ایجاد کنید و آن را به پنل موردنظر متصل کنید.

هنگام ساخت محصول می‌توانید آن را به یک دسته‌بندی اضافه کنید یا بدون دسته‌بندی ذخیره کنید.

### 6. تست خرید

یک محصول ارزان یا تستی بسازید و کل فرآیند را بررسی کنید.

### 7. کد تخفیف

برای تست سیستم تخفیف:

```text
Discount
→ افزودن کد
→ انتخاب Percent یا Amount
→ مقدار
→ مدت اعتبار
→ کد
→ ذخیره
```

سپس از طریق Bot یک سفارش ایجاد کنید و کد تخفیف را در مرحله پرداخت وارد کنید.

### 8. دسته‌بندی

برای تست دسته‌بندی:

```text
Product Categories
→ ساخت دسته‌بندی
→ ساخت / ویرایش محصول
→ انتخاب دسته‌بندی
→ مشاهده در Bot
```

### 9. Password Generator

برای تست Password Generator:

```text
Settings
→ Password Generator
→ وارد کردن تعداد کاراکتر
→ Generate
→ Copy
```
