# 🆕 تغییرات نسخه 1.0.2

در این نسخه بخش **مدیریت کاربران** و قابلیت حذف/مدیریت موارد مختلف به
پروژه اضافه شده است.

## 👥 مدیریت کاربران

ادمین می‌تواند تمام کاربرانی را که ربات را Start کرده‌اند مدیریت کند.

برای هر کاربر اطلاعاتی مانند:

-   ID عددی
-   Username
-   نام کاربر
-   موجودی کیف پول
-   وضعیت کاربر

نمایش داده می‌شود.

با انتخاب هر کاربر، عملیات مدیریتی در دسترس است.

### 💰 افزایش موجودی

ادمین مبلغ موردنظر را وارد می‌کند و موجودی کاربر افزایش پیدا می‌کند.

### ➖ کاهش موجودی

ادمین مقدار موردنظر را وارد می‌کند و قبل از انجام عملیات، موجودی فعلی
کاربر نمایش داده می‌شود.

### 📦 مشاهده سفارش‌های کاربر

ادمین می‌تواند سفارش‌های تأییدشده کاربر را مشاهده کند؛ از جمله:

-   سرویس‌های خریداری‌شده
-   کانفیگ‌ها
-   شارژهای کیف پول

### 🚫 مسدود کردن کاربر

ادمین می‌تواند کاربر را مسدود کند.

کاربر مسدودشده دیگر نمی‌تواند از امکانات ربات استفاده کند و ربات به
درخواست‌های او پاسخ عادی نمی‌دهد.

# 🗑️ حذف موارد مدیریتی

در نسخه `1.0.2` برای موارد مختلف مدیریتی قابلیت حذف اضافه شده است.

از جمله:

-   محصولات
-   پنل‌ها
-   Groupها
-   کانال‌های عضویت اجباری
-   سایر موارد قابل مدیریت

برای محصولاتی که سابقه سفارش دارند، بهتر است حذف به‌صورت **غیرفعال‌سازی**
انجام شود تا اطلاعات سفارش‌های قبلی از بین نرود.

------------------------------------------------------------------------

# 🌐 پنل مدیریت تحت وب

تمام قابلیت‌های جدید نسخه `1.0.2` در پنل مدیریت وب نیز در نظر گرفته
شده‌اند.

ادمین می‌تواند از طریق پنل وب:

-   کاربران را مشاهده کند.
-   موجودی کاربران را افزایش دهد.
-   موجودی کاربران را کاهش دهد.
-   سفارش‌های کاربران را ببیند.
-   کاربران را مسدود کند.
-   محصولات را مدیریت کند.
-   پنل‌ها را مدیریت کند.
-   Groupها را مدیریت کند.
-   کانال‌های عضویت اجباری را مدیریت کند.
-   تنظیمات ربات را مشاهده و مدیریت کند.

اطلاعات ربات و پنل وب از دیتابیس مشترک استفاده می‌کنند؛ بنابراین تغییرات
انجام‌شده از هر دو بخش قابل مشاهده هستند.

# 📢 عضویت اجباری چندکاناله

ادمین می‌تواند چند کانال را برای عضویت اجباری ثبت کند.

کاربر باید در تمام کانال‌های فعال عضو باشد.

روند:

``` text
ورود کاربر
    ↓
بررسی کانال‌ها
    ↓
نمایش کانال‌های موردنیاز
    ↓
عضویت
    ↓
بررسی مجدد
    ↓
ورود به ربات
```

# 👋 پیام خوش‌آمدگویی

متن پیام خوش‌آمدگویی از پنل مدیریت قابل تغییر است.

متغیرهای قابل استفاده:

``` text
{username}
{first_name}
{user_id}
```

``` text

```

# 💰 کیف پول

کاربر می‌تواند حساب خود را شارژ کند.

``` text
انتخاب مبلغ
    ↓
نمایش شماره کارت
    ↓
ارسال رسید
    ↓
تأیید ادمین
    ↓
افزایش موجودی
```

اگر موجودی برای خرید کافی باشد، خرید بدون تأیید دستی انجام می‌شود.

# 🛒 محصولات

هنگام ساخت محصول، ادمین مشخص می‌کند:

-   نام محصول
-   قیمت
-   پنل
-   حجم بر حسب GB
-   مدت بر حسب روز

کاربر هنگام خرید حجم یا زمان را انتخاب نمی‌کند و سرویس دقیقاً با تنظیمات
محصول ساخته می‌شود.

------------------------------------------------------------------------

# 🧪 تست رایگان

ادمین می‌تواند تعیین کند:

-   هر کاربر چند بار تست بگیرد.
-   حجم تست چند MB باشد.
-   تست چند ساعت اعتبار داشته باشد.

مثال:

``` text
تعداد تست: 2
حجم: 60 MB
زمان: 1 ساعت
```

کاربر حجم و زمان را انتخاب نمی‌کند و تست با همان تنظیمات ادمین ساخته
می‌شود.

پس از تمام شدن سهمیه:

``` text
محدودیت ساخت تست شما تمام شد.
```

# 📦 سرویس‌های من

# 🌐 Deploy روی Railway

1.  پروژه را در GitHub قرار دهید.
2.  در Railway یک Project ایجاد کنید.
3.  Repository را از GitHub انتخاب کنید.
4.  Variables را تنظیم کنید.
5.  Deploy کنید.
6.  برای پنل وب از بخش **Networking → Generate Domain** دامنه بسازید.
