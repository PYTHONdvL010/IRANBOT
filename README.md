# 📢 عضویت اجباری چندکاناله

در نسخه `1.0.1` امکان اضافه کردن چند کانال به عضویت اجباری وجود دارد.

ادمین می‌تواند چند کانال مختلف ثبت کند و کاربر باید در تمام کانال‌های فعال
عضو باشد.

برای هر کانال می‌توان اطلاعات مربوط به کانال و لینک عضویت را تنظیم کرد.

روند کار:

``` text
کاربر وارد ربات می‌شود
        ↓
بررسی عضویت در کانال‌ها
        ↓
نمایش کانال‌های موردنیاز
        ↓
عضویت کاربر
        ↓
بررسی عضویت
        ↓
ورود به ربات
```

# 👋 پیام خوش‌آمدگویی

ادمین می‌تواند متن خوش‌آمدگویی را از پنل مدیریت تغییر دهد.

متغیرهای قابل استفاده:

سلام {username} 👋

# 💰 شارژ کیف پول

کاربر مبلغ موردنظر را وارد می‌کند.

سپس شماره کارت ثبت‌شده نمایش داده می‌شود و کاربر رسید را ارسال می‌کند.

روند:

``` text
مبلغ شارژ
   ↓
شماره کارت
   ↓
ارسال رسید
   ↓
ادمین
   ↓
تأیید
   ↓
افزایش موجودی
```

# 🛒 ساخت محصول

ادمین هنگام ساخت محصول موارد زیر را مشخص می‌کند:

-   نام محصول
-   قیمت
-   پنل
-   حجم بر حسب GB
-   مدت بر حسب روز

مثال:

``` text
نام: سرویس ویژه
حجم: 50 GB
مدت: 30 روز
قیمت: 150000 تومان
```

کاربر هنگام خرید حجم یا مدت را انتخاب نمی‌کند و سرویس دقیقاً با مشخصات
تنظیم‌شده محصول ساخته می‌شود.

# 🖥️ پنل‌های پشتیبانی‌شده

# 🔗 Pasarguard Groups

ساختار اتصال سرویس در Pasarguard:

``` text
User
 ↓
Group
 ↓
Inbound Tags
 ↓
Host
```

بات Groupهای قابل دسترسی را دریافت کرده و هنگام ساخت کاربر از Group
انتخاب‌شده استفاده می‌کند.

# 🧪 تست رایگان

ادمین می‌تواند تنظیمات تست رایگان را مشخص کند:

-   تعداد تست مجاز هر کاربر
-   حجم تست بر حسب MB
-   مدت تست بر حسب ساعت

مثال:

``` text
تعداد تست: 2
حجم: 60 MB
زمان: 1 ساعت
```

کاربر حجم و زمان را انتخاب نمی‌کند؛ تست دقیقاً با همان تنظیمات ادمین ساخته
می‌شود.

پس از تمام شدن سهمیه:

``` text
محدودیت ساخت تست شما تمام شد.
```

نمایش داده می‌شود.

# 📦 سرویس‌های من

در بخش سرویس‌ها فقط سرویس‌های تأییدشده نمایش داده می‌شوند.

پرداخت‌های در انتظار مانند:

``` text
awaiting_payment
```

به‌عنوان سرویس فعال نمایش داده نمی‌شوند.

هر سرویس دکمه جداگانه دارد و کاربر می‌تواند مشخصات و لینک Subscription
همان سرویس را مشاهده کند.

------------------------------------------------------------------------

# 🌐 پنل مدیریت تحت وب

IRANBOT دارای پنل مدیریت تحت وب است.

پس از Deploy روی Railway:

``` text
Railway
 → Service
 → Networking
 → Generate Domain
```

دامنه ایجادشده را باز کنید.

پنل وب با `PORT` اختصاص داده‌شده توسط Railway اجرا می‌شود.

ورود پنل فقط برای IDهای موجود در:

``` env
ADMIN_IDS
```

امکان‌پذیر است.

# ☁️ Deploy روی Railway

1.  Repository را در GitHub قرار دهید.
2.  وارد Railway شوید.
3.  یک Project ایجاد کنید.
4.  Repository را از GitHub انتخاب کنید.
5.  Variables را تنظیم کنید.
6.  Deploy کنید.
7.  برای پنل وب از Networking گزینه Generate Domain را بزنید.

وجود `Dockerfile` باعث می‌شود Railway بتواند پروژه را به‌صورت Docker اجرا
کند.
