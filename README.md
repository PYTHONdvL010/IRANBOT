# Config Shop Bot — Railway

**Project version: IRANBOT v1.0.4**

نسخه کامل ربات فروش کانفیگ/سرویس VPN برای Telegram و Railway، با دیتابیس SQLite و Web Panel مدیریت.

> این README مربوط به **همان نسخه v1.0.4** است. شماره نسخه تغییر نکرده است.

## امکانات اصلی

### ربات Telegram
- فروش محصول و نمایش محصولات
- ساخت سفارش و نمایش سفارش‌های کاربر
- بخش «سرویس‌های من» و نمایش Subscription هر سرویس
- پروفایل کاربر
- کیف پول و شارژ کیف پول با رسید پرداخت
- پرداخت مستقیم محصول با رسید پرداخت
- پشتیبانی کاربر و ارسال پیام/عکس برای ادمین
- عضویت اجباری در چند کانال
- پیام خوش‌آمد قابل تنظیم
- تست رایگان با محدودیت‌های قابل تنظیم
- کد تخفیف

### پنل‌ها و API
- پشتیبانی از **Marzban / Pasarguard / 3x-ui**
- ثبت پنل از داخل Web Panel
- تست اتصال پنل
- ساخت سرویس بعد از تأیید پرداخت
- پشتیبانی از Pasarguard Group
- انتخاب چند Group برای ساخت سرویس
- تبدیل Subscription نسبی مثل `/sub/...` به لینک کامل بر اساس آدرس پنل

### پرداخت و کیف پول
- ثبت شماره کارت و نام صاحب کارت توسط ادمین
- پرداخت مستقیم با ارسال رسید
- تأیید/رد پرداخت توسط ادمین
- شارژ کیف پول با رسید و تأیید ادمین
- در صورت کافی بودن موجودی، خرید از کیف پول بدون تأیید دستی انجام می‌شود
- در صورت کافی نبودن موجودی، کاربر به پرداخت با کارت هدایت می‌شود
- بعد از تأیید پرداخت، سرویس به‌صورت خودکار ساخته و لینک Subscription برای کاربر ارسال می‌شود
- شماره کارت و نام صاحب کارت در صفحه اصلی کیف پول نمایش داده نمی‌شود و فقط در مرحله پرداخت نمایش داده می‌شود

## مدیریت کاربران

مدیریت کاربران **فقط از Web Panel** انجام می‌شود و بخش مدیریت کاربران از منوی ادمین ربات حذف شده است.

Web Panel امکان‌های زیر را دارد:
- جستجوی کاربران
- مشاهده موجودی
- افزایش/کاهش موجودی
- مسدود/فعال کردن کاربر
- مشاهده اطلاعات پایه کاربر
- نمایش تعداد کاربران در داشبورد
- ارسال اعلان تلگرامی هنگام تغییر موجودی از Web Panel

کاربر از همان `/start` در دیتابیس ثبت می‌شود، حتی اگر هنوز عضویت اجباری را کامل نکرده باشد.

## Web Panel

بعد از Deploy در Railway، برای سرویس یک Domain بساز و Web Panel را از آدرس اصلی سرویس باز کن.

بخش‌های اصلی:
- Dashboard
- Users
- Welcome Message
- Mandatory Membership
- Finance / Payments
- Panels
- Pasarguard Groups
- Products
- Orders
- Free Test
- Discount

Web Panel به‌صورت Responsive طراحی شده و داشبورد آماری برای کاربران، محصولات، سفارش‌ها، پرداخت‌ها و پنل‌ها دارد.

## تست رایگان

تنظیمات تست رایگان از Web Panel انجام می‌شود:
- حداکثر تعداد تست برای هر کاربر
- حجم به MB
- مدت اعتبار به ساعت
- فعال/غیرفعال بودن تست
- پنل مورد استفاده
- Groupهای Pasarguard انتخاب‌شده

کاربر حجم و زمان را خودش انتخاب نمی‌کند؛ مقادیر دقیق تنظیم‌شده توسط ادمین استفاده می‌شوند.

## عضویت اجباری

امکان تعریف چند کانال اجباری وجود دارد.

کاربر باید در تمام کانال‌های تعیین‌شده عضو باشد. برای هر کانال دکمه جداگانه نمایش داده می‌شود و دکمه بررسی عضویت همه کانال‌ها نیز وجود دارد.

ادمین‌ها از محدودیت عضویت اجباری مستثنی هستند.

## متغیرهای Railway

```text
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
ADMIN_IDS=123456789
DB_PATH=/app/data/shop.db
PORT=8080
WEB_SECRET=OPTIONAL_SECRET
```

`WEB_SECRET` اختیاری است. اگر تنظیم شود، برای ورود به Web Panel استفاده می‌شود.

## دیتابیس

ربات از SQLite استفاده می‌کند.

پیشنهاد می‌شود در Railway یک **Volume** با مسیر زیر متصل شود:

```text
/app/data
```

تا دیتابیس بعد از Redeploy یا Restart از بین نرود.

## نصب روی Railway

1. فایل ZIP را در پروژه قرار بده.
2. Repository/Source را به Railway متصل کن.
3. متغیرهای محیطی بالا را تنظیم کن.
4. یک Volume با مسیر `/app/data` بساز.
5. Deploy را انجام بده.
6. از بخش Networking برای سرویس یک Public Domain بساز.
7. آدرس Domain را برای ورود به Web Panel استفاده کن.

## نکته مهم برای تحویل خودکار سرویس

برای تحویل خودکار، محصول باید به یک پنل ثبت‌شده متصل باشد.

برای Pasarguard باید حداقل یک Group انتخاب شده باشد تا ساخت سرویس بتواند از Groupهای انتخاب‌شده استفاده کند.
