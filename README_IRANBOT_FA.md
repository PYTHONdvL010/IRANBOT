# 🤖 IRANBOT \| ربات فروش سرویس و مدیریت پنل

> **IRANBOT** یک ربات تلگرامی برای فروش و مدیریت سرویس‌های
> VPN/Subscription است که با Python ساخته شده و قابلیت اتصال به پنل‌های
> **Pasarguard، Marzban و 3x-ui** را دارد.

**Version:** `1.0.0`\
**ساخته شده با:** `Python`\
**سازنده:** `PYTHONdvL010`

# 🚀 نصب و اجرا

## پیش‌نیازها

-   Python `3.11+`
-   یک Bot Token از BotFather
-   دسترسی API به پنل VPN
-   ترجیحاً Railway برای اجرای 24 ساعته

------------------------------------------------------------------------

## 1. ساخت ربات تلگرام

در Telegram وارد **@BotFather** شوید و دستور زیر را اجرا کنید:

``` text
/newbot
```

نام و username ربات را انتخاب کنید و **BOT TOKEN** را دریافت کنید.

> ⚠️ توکن ربات را داخل GitHub قرار ندهید.

------------------------------------------------------------------------

# 2. تنظیم متغیرهای محیطی

در Railway یا فایل محیطی، متغیرهای زیر را تنظیم کنید:

``` env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
ADMIN_IDS=123456789
DB_PATH=/app/data/shop.db
```

### توضیح متغیرها

  متغیر         توضیح
  ------------- ---------------------
  `BOT_TOKEN`   توکن ربات تلگرام
  `ADMIN_IDS`   آیدی عددی ادمین‌ها
  `DB_PATH`     مسیر دیتابیس SQLite

برای چند ادمین می‌توانید آیدی‌ها را با کاما جدا کنید:

``` env
ADMIN_IDS=123456789,987654321
```

# ☁️ Deploy روی Railway

## روش پیشنهادی

1.  پروژه را در GitHub قرار دهید.
2.  وارد Railway شوید.
3.  یک Project جدید بسازید.
4.  گزینه **Deploy from GitHub Repo** را انتخاب کنید.
5.  Repository مربوط به IRANBOT را انتخاب کنید.
6.  متغیرهای محیطی را در بخش **Variables** وارد کنید.
7.  Deploy را انجام دهید.

اگر پروژه دارای `Dockerfile` باشد، Railway می‌تواند از آن برای Build
استفاده کند.

# 💾 ذخیره دائمی دیتابیس

IRANBOT از SQLite استفاده می‌کند.

برای اینکه با Restart یا Redeploy اطلاعات کاربران، سفارش‌ها، محصولات و
تنظیمات از بین نرود، در Railway یک **Volume** بسازید.

مسیر Mount پیشنهادی:

``` text
/app/data
```

و متغیر:

``` env
DB_PATH=/app/data/shop.db
```

> بدون Volume ممکن است دیتابیس SQLite بعد از بعضی Deployها یا تغییرات
> محیطی از بین برود.

------------------------------------------------------------------------

# 🌐 پنل مدیریت تحت وب

IRANBOT دارای پنل مدیریت تحت وب است.

بعد از Deploy روی Railway:

1.  وارد Service شوید.
2.  بخش **Networking** را باز کنید.
3.  گزینه **Generate Domain** را بزنید.
4.  دامنه ایجادشده را باز کنید.

پنل وب از `PORT` اختصاص داده‌شده توسط Railway استفاده می‌کند.

### ورود به پنل

در صفحه ورود، **آیدی عددی ادمین** را وارد کنید.

فقط IDهایی که در:

``` env
ADMIN_IDS
```

قرار دارند اجازه ورود دارند.

# 📢 عضویت اجباری

از پنل مدیریت:

``` text
🛠 پنل مدیریت
   ↓
📢 عضویت اجباری
```

کانال موردنظر را تنظیم کنید.

برای اینکه بررسی عضویت درست کار کند، ربات باید در کانال موردنظر دسترسی
لازم برای بررسی اعضا را داشته باشد.

پیشنهاد می‌شود ربات را در کانال به‌عنوان Administrator اضافه کنید.

# 🔐 Pasarguard و Group

در Pasarguard، سرویس‌ها از طریق **Group** به Inboundها متصل می‌شوند.

ساختار کلی:

``` text
User
  ↓
Group
  ↓
Inbound Tags
  ↓
Host
```

بنابراین در IRANBOT ابتدا Groupهای قابل دسترسی از پنل دریافت می‌شوند.

پس از انتخاب Group، سرویس‌های ساخته‌شده برای کاربر با همان Group ایجاد
می‌شوند.

اگر حساب API فقط اجازه مشاهده Groupهای ساده را داشته باشد، ممکن است نام
Inbound Tagها در بات قابل مشاهده نباشد؛ اما تخصیص Group همچنان می‌تواند
انجام شود، مشروط به اینکه سطح دسترسی API اجازه آن را بدهد.

# 🛒 ساخت محصول

ادمین هنگام ساخت محصول مشخص می‌کند:

-   نام محصول
-   قیمت
-   پنل
-   حجم بر حسب GB
-   مدت سرویس بر حسب روز

مثال:

``` text

قیمت: 150000 تومان
حجم: 50 GB
مدت: 30 روز
```

هنگام خرید، همین مشخصات برای ساخت خودکار سرویس استفاده می‌شوند.

# 💰 کیف پول

کاربر از منوی:

``` text
💰 کیف پول
```

می‌تواند موجودی خود را مشاهده کند.

برای افزایش موجودی:

``` text
افزایش موجودی
      ↓
وارد کردن مبلغ
      ↓
نمایش شماره کارت
      ↓
ارسال رسید
      ↓
تأیید ادمین
      ↓
افزایش موجودی
```

اگر موجودی برای خرید کافی باشد:

``` text
کیف پول
   ↓
بررسی موجودی
   ↓
کسر مبلغ
   ↓
ساخت خودکار سرویس
   ↓
ارسال لینک
```

# 🧪 تست رایگان

ادمین می‌تواند از پنل مدیریت مقدار تست را تنظیم کند:

``` text
تعداد تست برای هر کاربر
حجم تست (MB)
مدت تست (ساعت)
```

مثلاً:

``` text
تعداد: 2
حجم: 60 MB
مدت: 1 ساعت
```

در این حالت کاربر با هر بار درخواست تست، مستقیماً یک تست:

``` text
60 MB
1 ساعت
```

دریافت می‌کند.

کاربر نمی‌تواند حجم یا زمان تست را تغییر دهد.

پس از تمام شدن سهمیه:

``` text
محدودیت ساخت تست شما تمام شد.
```

نمایش داده می‌شود.
